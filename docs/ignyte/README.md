# Ignyte Challenges material

Harbor started as an entry to the Ignyte Challenges (DIFC × Polygon). We built it between 27 June and 13 July 2026 and submitted it in July.

These files are a record of how we planned and pitched the submission. They describe the project as it was then, so some file paths and plans are out of date. For the current state, start at the [main README](../../README.md).
